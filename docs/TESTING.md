# Beta testing checklist (v0.1.1)

Thank you for testing. Please try as many of these as you like and report what does not work as described. Every report helps even when it is just "worked on <device>".

## Everyone
1. Start-up: the pick screen shows `v0.1.1 beta`; start each game you own; leave and come back (autosave resume).
2. Tabs in the field and in a battle: Party, Psynergy, Djinn, Map, Items, Menu. In a battle tap another tab, then the footer ("Tap here: back to the battle").
3. Tap to equip an item (stat preview), **Equip best**, cast a field Psynergy, flip a Djinn, Djinn sets, **Repeat round**.
4. The Map tab: the whole area is drawn from your ROM with your position marked (USA / Europe cartridges).
5. The Lost Age: start a new game without a password. The party cards should show Felix, Jenna, Mia (then Jenna alone), never four Isaacs. The footer should name the area.

## Android
6. Add a ROM from the start-up screen; hold a game's card to remove it; add it again.
7. Layouts: portrait, landscape, a controller connected (buttons hide in Auto).
8. Menu > **Settings**: top screen Fill / 1x, button size / opacity / vibration, fast-forward speed (2x-16x), swap screens (two displays), Export saves, Import saves (try this before uninstalling).
9. Sound: crackle, delay, stutter at normal speed and at fast forward.
10. Press Home and come back; kill the app and start it again (autosave).
11. Dual-screen handhelds: which display is the touch screen, does ZL swap them, does touch work on both.

## What to include in a report
- The device (model, Android version, or New / Old 3DS and real hardware or an emulator) and the game.
- What you did, what you expected, what happened; a photo or screenshot if it is visual.
- Android: **Menu > Settings > page 2 > Copy debug info**, then paste it into the issue. 3DS: the footer line on the Menu tab (`NNfps ... eMM ... cNN`).
- Open the issue at the repository's Issues tab (the bug template asks for the same things).
